# PicTrace Growth Audit

**Live → https://eddieatadapty.github.io/pictrace-flow-rebuild-v2/**

Five ideas to turn more PicTrace users into subscribers, each built into a clickable version of PicTrace's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Make sure the first paywall shows its prices | +5–20% CR to purchase · fix first |
| 02 | Let them trace one sketch before the paywall | +10–15% CR to purchase |
| 03 | Ask what they want to draw, then use the answer | +10–15% CR to purchase |
| 04 | Put the yearly next to the weekly, in the same unit | +10–15% ARPU |
| 05 | An honest offer when they close | +5–10% ARPU |

Every price, rating and feature comes from PicTrace's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for PicTrace. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
